## Runtime Launch Registry

Keep this registry current with runtime launch surfaces. Use paths relative to the repository root.

### Shared Runtime Flags

| scope | flags | notes |
| --- | --- | --- |
| Root `engine` launcher | `--project <path>` or `--project=<path>` | Required. Points at an `engine.project.toml`. |
| Root `engine` launcher | `--scene <path>` or `--scene=<path>` | Optional scene override. If absent, uses the project's `startup_scene`. |
| Root `engine` launcher | `--headless` | Uses the headless runtime path. |
| Root `engine` launcher | `-h`, `--help` | Prints usage. Cannot be combined with runtime options. |
| Root `engine` and renderer examples | `--record_debug <seconds>`, `--record_debug=<seconds>` | Starts debug timing capture. Value must be >= 1. |
| Root `engine` and renderer examples | `--record_debug_interval <ms>`, `--record_debug_interval=<ms>` | Debug timing sample interval. Value must be >= 1. |
| Root `engine` and renderer examples | `--record_debug_path <path>`, `--record_debug_path=<path>` | Writes debug timing JSONL to an explicit path. |
| Root `engine` and renderer examples | `--capture_target <present\|draw>`, `--capture_target=<present\|draw>` | `present` is default. Use `draw` for headless draw-target validation. |
| Root `engine` and renderer examples | `--capture_frame <n>`, `--capture_frame=<n>` | Single frame capture. Root/examples require positive `n`. |
| Root `engine` and renderer examples | `--capture_frame_path <path>`, `--capture_frame_path=<path>` | Requires `--capture_frame`. |
| Root `engine` and renderer examples | `--capture_frames <n>`, `--capture_frames=<n>` | Sequence capture count. Requires `n >= 1`. |

| Dogfood | `--capture_frame_start <n>` | Requires `--capture_frames`. Current dogfood parser accepts non-negative `n` and does not accept equals form. |
| Root `engine` and renderer examples | `--capture_frame_interval <n>`, `--capture_frame_interval=<n>` | Requires `--capture_frames`; `n >= 1`. |
| Dogfood | `--capture_frame_interval <n>` | Requires `--capture_frames`; `n >= 1`. Current dogfood parser does not accept equals form. |
| Root `engine` and renderer examples | `--capture_dir <dir>`, `--capture_dir=<dir>` | Requires `--capture_frames`. |
| Dogfood | `--capture_dir <dir>` | Requires `--capture_frames`. Current dogfood parser does not accept equals form. |
| Root `engine` and renderer examples | `--manual_capture_dir <dir>`, `--manual_capture_dir=<dir>` | Directory used for manual capture requests. |
