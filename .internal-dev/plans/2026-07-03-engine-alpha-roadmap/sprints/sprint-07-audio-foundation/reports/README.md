# Reports

Use this directory for sprint-specific report artifacts that are not validation reports.

Expected artifacts:

- `planning-email.md` after planning handoff if the main thread wants a planning closeout email.
- `phase-01-email.md` after Phase 01 validation.
- `phase-02-email.md` after Phase 02 validation.
- `phase-03-email.md` after Phase 03 validation.
- `phase-04-email.md` after Phase 04 validation.
- `dogfood-audio-proof-debt.md` if Phase 03 defers dogfood/sample playback proof.

Workers and validators should not send email. The main thread owns email transport, push/commit gates, sprint tracker updates, and changelog timing confirmation.
