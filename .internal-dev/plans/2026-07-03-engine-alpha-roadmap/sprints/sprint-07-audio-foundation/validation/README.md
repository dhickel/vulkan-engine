# Validation Reports

Validators must write:

- `phase-01-validation-report.md`
- `phase-02-validation-report.md`
- `phase-03-validation-report.md`
- `phase-04-validation-report.md`
- `final-quality-review.md`

Each report should include:

- criteria pass/fail;
- commands run and results;
- evidence inspected;
- whether device-backed playback smoke was not applicable, skipped, blocked, or passed;
- whether browser/headless draw proof was required;
- findings and remediation routing;
- residual risk.

Do not mark `artifacts/validation-summary.json` as `fully_validated` until all required phase validators and final quality review pass.
