# Reports

Phase workers draft email/report files here:

- `phase-01-email.md`
- `phase-02-email.md`
- `phase-03-email.md`
- `phase-04-email.md`
- optional `final-email.md`

Each report should include:

- phase objective;
- files changed;
- validation commands and results;
- capture applicability;
- residuals/blockers;
- next-phase readiness;
- short HTML-email-ready summary.

The main thread sends HTML email after validator pass and owns any external coordination.
