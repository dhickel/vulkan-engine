# Reports

This directory is for Sprint 11 closeout and communication artifacts.

Expected files after execution:

- `api-friction.md`: API gaps or schema pain discovered while dogfooding.
- `migration-debt.md`: any deliberate dogfood-only content/runtime debt that remains.
- `final-report.md`: final user-facing closeout summary.
- `planning-email.md` or `final-email.md`: draft email/report content only if the main thread uses AgentMail.

Email sending and waiting are out-of-band main-thread responsibilities. Planning artifacts should provide content and evidence paths, not send or wait mechanics.
