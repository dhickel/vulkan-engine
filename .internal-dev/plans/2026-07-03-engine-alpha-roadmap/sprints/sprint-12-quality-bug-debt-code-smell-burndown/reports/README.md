# Reports README

Workers should write phase reports here:

- `reports/phase-01-residual-inventory.md`
- `reports/phase-02-vulkan-lifecycle-hardening.md`
- `reports/phase-03-runtime-panic-stall-hardening.md`
- `reports/phase-04-docs-examples-test-drift.md`
- `reports/phase-05-final-residual-acceptance.md`

Each report should include:

- objective and scope actually handled;
- files changed;
- commands run;
- evidence paths;
- residuals found;
- bugs created or updated;
- deviations from the directive;
- next handoff.

Do not store large logs directly in reports. Link to `.internal-dev/debug_reports/`, `.internal-dev/captures/`, or other evidence paths.
