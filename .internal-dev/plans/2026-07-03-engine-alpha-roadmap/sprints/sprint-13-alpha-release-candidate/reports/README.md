# Reports

Worker reports belong here:

- `phase-01-release-inventory.md`
- `phase-02-fresh-clone-validation.md`
- `phase-03-sample-editor-runtime-proof.md`
- `phase-04-dogfood-run-visual-proof.md`
- `phase-05-release-notes-known-issues-final.md`

Reports should summarize commands and link evidence paths. Do not paste giant logs unless a small excerpt is needed to explain a blocker.

Each report must include:

- branch/commit inspected;
- files changed;
- commands run and results;
- capture/debug artifact paths;
- residual risks;
- protected-path and tracker checks;
- handoff to validator.
